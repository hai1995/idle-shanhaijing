# 山海经 · 放置挂机 —— 著录

一款以《山海经》为题材的纯前端放置挂机网页游戏（原生 JS，零依赖、无需构建、可离线运行）。

> 当前版本 **v1.6.0**（代号「密都 · 岳祠」）· 更新于 2026-10-24。版本号与更新日期集中于 `GAME_META`（`src/gameData.js`），「叙录」页直接读取，不散落硬编码。
玩家扮演**著录者**，受命巡行南山，采集、制作、讨伐、御使、祭祀，把山川万物逐条录于竹简——游戏进度即一部正在写成的《山海经》。

- **技术形态**：纯静态站点（无后端），可直接部署 GitHub Pages；`localStorage` 存档，支持导出 / 导入；可选接入自托管云端存档（`server/cloud-save-server.js`，零依赖）实现多设备进度合并。
- **玩法骨架**：采用放置类游戏的通用设计模式（技能训练—挂机推进—离线结算、采集—加工—消耗三级闭环）；这部分属于不受著作权保护的通用设计。
- **内容来源**：世界观、山名、异兽、祠礼、征兆全部取自《山海经》原文（中华书局点校本《山海经校注》袁珂，公有领域）；所有数值、机制、命名均为本项目**自研调参**，未沿用任何既有产品。

## 界面（「朱墨套印本」）

视觉按一部双色套印古籍来做：**墨为骨、朱为记、青为纲**。全站只用三个功能色，且各有唯一职责——

| 色 | 变量 | 只用于 |
|---|---|---|
| 朱 `#B03A2B` | `--zhu` | 「此刻」与「动作」：当前页签、主按钮、进度、当前阶 |
| 石青 `#2E5269` | `--qing` | 「结构」：篇名、章节、链接、选中态 |
| 苔绿 `#566E4C` | `--tai` | 「所得」：增益、达成、已录 |

- **昼夜双态**：同一套「朱墨套印」色系延伸出两态——昼为纸底墨字，夜为暖炭底墨白字，夜间三色（朱/青/苔）微提亮以承夜光；顶栏「书脊」昼夜皆取最深一档，书脊不随室光而变。切换入口收在侧边栏末尾的「设置」页（昼夜一栏）（白昼 / 黑夜两态按钮），选择记入 `localStorage`，首次访问时跟随系统 `prefers-color-scheme`，切换过程带 0.3s 柔和过渡并在 `prefers-reduced-motion` 下降级为瞬切。
- **字体双声部**：标题用楷（`--f-kai`）作「书的声音」，正文用系统黑体（`--f-sans`）作「器物的声音」，数字统一等宽宋（`--f-num`）以免跳数。全部为系统字体栈，零外部依赖、离线可用。
- **平铺不叠影**：承载面一律 `1px` 细线 + 近直角（`2px`），不用圆角卡片与投影堆叠；层次靠留白与线建立。
- **原文竖排**：宽屏下山志「原文」以 `writing-mode:vertical-rl` 竖排呈现（窄屏回落横排）。这是全站唯一「用力」的地方，其余保持安静。
- **信息密度**：宽屏舆地为三栏「书案」布局（山系 / 诸山 / 山志各自滚动，整屏不空）；未解锁山系、一次未著录的异兽、未达标的异兽名单均折叠，避免开屏即长名单；图鉴 849 条提供名/注音检索。
- **无障碍基线**：`:focus-visible` 焦点环、`prefers-reduced-motion` 降级、触控目标 ≥ 38px、文字对比度 ≥ 4.5:1（三级文字仍可读）。浮动通知层（toast）`pointer-events:none` 且落于顶栏之下，不遮挡、不吞点击。
- **交互反馈**：顶栏数值用等宽数字、变动时一次极短「落笔」高光；长页滚过一屏浮现「回到顶部」；图鉴检索命中以朱色淡底标出；空态（如御使无达标异兽）直接给出下一步行动按钮，不留死胡同。
- 样式全部集中在 `style.css`；`test/engine.test.js` 中有一组设计审计断言（色板、断点、抽屉宽度、网格密度、CSS 变量是否全部有定义等），改样式时同步维护。


## 运行方式

- **本地预览**：根目录起任意静态服务器，如 `npx serve` 或 `python -m http.server 8080`；直接双击 `index.html` 亦可游玩（个别浏览器下 `localStorage` 可能受限）。
- **部署**：推送到 GitHub 仓库 `main` 分支根目录，`Settings → Pages` 选 `main` / `(root)` 即可（已带 `.nojekyll`）。
- **云端存档（可选）**：想多设备续玩才需要。起一个参考后端 `node server/cloud-save-server.js --port 8787 --token 你的令牌`（零依赖，接口约定见 `CLOUD_SAVE.md`），再到「设置 → 存档」填地址与令牌即可；停止操作约 3 秒自动上传，离开页面强传一次，拉取时与本地进度按规则合并。不填则纯本地，与旧版行为一致。

## 世界结构

《山海经》的地理层级本身就是进度系统：**山系 → 区域，山 → 资源节点**。当前实现**南山经三系 39 山 + 西山经四系 77 山 + 北山经三系 88 山 + 东山经四系 46 山 + 中山经首录六系 67 山（共 317 山、26 山系、五章）**（数据源 `nanshanjing_nodes.json` / `xishanjing_nodes.json` / `beishanjing_nodes.json` / `dongshanjing_nodes.json` / `zhongshanjing_nodes.json`，派生为 `src/nanshanData.js` / `src/xishanData.js` / `src/beishanData.js` / `src/dongshanData.js` / `src/zhongshanData.js`；改 JSON 后运行 `node scripts/gen-world-data.js` 重新生成）。

- **章节**：第一章·南山经（巡行记录）→ 第二章·西山经（神话舞台，神祇密度支撑主线章节）→ 第三章·北山经（长篇养成，精卫填海）→ 第四章·东山经（异兽谱系收束）→ 第五章·中山经（帝之密都，全书收卷；首录中次一至六经 67 山，中次七至十二经诸山待补录）。
- **等级重排**：技能上限 81（九九八十一）。五章全球调参等级统一重排进 1–81：南山 raw[1,75] → [1,26]、西山 raw[78,275] → [27,42]、北山 raw[280,529] → [43,56]、东山 raw[535,690] → [57,68]、中山前三系 raw[691,749] → [69,73]（已上线，斜率固定）、后九系 raw[753,950] → [74,81]（两段式，补录不回头改旧章；后八系 raw 顺序紧排——中次十一经 48 山为全书最长系，均匀布局会溢出上限；已录：中次四经 753–775、中次五经 777–791、中次六经 793–806），原始调参值保留在各节点 `dataUnlockLevel` 字段，便于日后重新调参。
- 区域 / 节点按「舆地」等级解锁；三处「不可以上」之山另需「履险」等级。
- **舆地经验耦合**：一切修行（采集/制作/讨伐/祀/观）所得的 10% 同时长「舆地」、其半长「履险」——否则仅靠首访给经验，317 山的世界在真实游玩中永远走不通。
- 每座山的产出（其木多 X / 其阳多玉 / 有兽焉）直接来自原文，节点面板可查阅原文节录与神话段落。
- 征兆（原文「见则 X」）共 **45 条**（南山 8 + 西山 15 + 北山 4 + 东山 15 + 中山 3）：首次著录该异兽即触发全局吉凶事件，可卜筮预知、以祠祀禳解；**兵灾类可被御使駮「可以御兵」所御，鵕鸟/大鹗之诛赐予对应免疫；大风类（北山·山𤟤）影响移动效率、有恐类（北山·酸与）令卜筮失准；中山鸣蛇之大旱与化蛇/夫诸之大水为全书收卷的双重水旱兆**。
- 观象 / 观瑞 9 处（南山 5 + 东山 4），**谒见神祇 10 处**（西山），养成点 **3 处**（峚山「玉膏灌丹木」五岁、咸山「器酸三岁」、发鸠山「精卫填海」——后两者为北山原文自带的长周期）。
- 特殊节点：积石之山（全产出）、鸟鼠同穴（共生采集）、昆仑（田地威胁）；北山新增白沙山（沙漠，与橐驼「善行流沙」配套）、洹山三桑（高百仞，需高阶樵采）、教山（冬干夏流季节河）、空桑（冬夏有雪）。**北次一经全域「生食不火」——燔燎/调鼎在该区禁用**。

## 核心系统

- **著录度**（替代通用熟练度）：每个可采集物 / 异兽 / 山川 / 神祇独立累积，五阶「初见 → 识名 → 明性 → 通形 → 得御」，阈值 1/10/25/50/100 次，阶位产出加成 +0/+8/+18/+32/+50%；每阶揭示一段原文，达标后解锁御使资格。
- **御使**（替代召唤）：异兽需著录至「通形」方可入槽，槽位随御使等级扩充（每 10 级 +1，至 9 槽）。异兽提供的是被动增益与自动作业（如狌狌「食之善走」提采集速度、鹿蜀「佩之宜子孙」助田事），符合「驯养使役」而非「召唤仆从」。**蛮蛮「一翼一目，相得乃飞」——成对御使，占两槽**。
- **征兆系统**：原文「见则 X」共 45 条，首次著录即触发；凶兆不是纯惩罚——可禳解、可卜筮预知、吉凶可对冲。灌灌「佩之不惑」使凶兆减半、卜筮必吉；駮「可以御兵」御兵灾；鵕鸟/大鹗之诛赐予对应免疫。北山新增大风（拖慢移动）、有恐（卜筮失准）两类全新 debuff；东山新增螽蝗为败（采集/制作下降）、多狡客（商旅/战利下降）、多疫/大疫（产出/离线下降）四类 debuff；中山经收卷双兆——鸣蛇大旱与化蛇/夫诸大水（水旱对冲）。
- **祠礼**：**二十二套（含常祭）**（南山三系 + 西山四系 + 北山三系 + 东山四系 + 中山六系，祭法各异：太牢 / 少牢 / 雄鸡 / 羭山百牲斋百日 / 吉玉稷米 / 白鸡祈 / 白狗祈 / 璋玉瘗 / 北山瘗 / 北山投 / 北山玉璧瘗 / 东山犬鱼 / 东山鸡璧 / 东山羊黍 / 东山大牢 / 中山太牢吉玉 / 中山雄鸡糈瘞 / 中山一物祈珪 / 中山白鸡彩衣 / 中山肥牲吉玉 / 中山雄鸡禳祭），「瘗」与「祈」仪式不同；行祭给该山系产出增益并收录山神。祠祀可排入巡历队列。
- **谒见**：西次三经神祇不可讨伐——前往其山行谒见之礼，入图鉴并得祭祀经验（陆吾/西王母/帝江为守关 BOSS，走讨伐）。
- **养成**：峚山「玉膏灌丹木，五岁乃成」——原文自带的长周期，五岁满得丹木与其果实。
- **五行战斗**（替代战斗三角）：相克 ×1.35 / 被克 ×0.75 / 同属 ×1.00 / 相生增益 ×1.15。战斗以「讨伐派遣」自动结算为主；异兽五行自研设定。
- **BOSS 序列**：六凶（凿齿三连啮 / 九婴五行嬗变 / 大风飘风闪避 / 猰貐革甲破甲 / 修蛇蛇毒 / 封豨半血狂暴）+ 刑天（无首重击）+ **西山三神（陆吾九部连击 / 西王母善啸震慑 / 帝江混沌嬗变）**——机制各异，非数值换皮。
- **句式模板**：全部消耗品文案统一用原文句式——「食之 X」（食之不饥 / 善走 / 无肿疾）、「佩之 X」（佩之不迷 / 不畏 / 不惑）、「可以 X」（可以为底 / 已痔 / 释劳）。

## 数值（自研，全部集中在 `TUNING` 常量表）

- 等级：每技能 **81 级 9 阶**（一九…九九），不用常见 99/100/120 上限。
- 经验曲线：`XP(L→L+1) = round(20·L^2.15 + 10·1.048^L)`，可配置、可调。
- 掉落：权重公式 `base × (1+0.02·(等级−需求)) × (1+0.3·著录阶/4)`，clamp [0.1, 5]。
- 离线结算：`offlineGain = onlineRate × eff × min(时长, 上限)`；eff = 0.55 + 0.05×相关技能加成（cap 0.85），上限 12h（仓廪 +2h、每处观象 +1h）。
- 以上均为调参起点，改 `src/gameData.js` 顶部的 `TUNING` 即可批量调整。

## 界面

竹简 / 绢帛 / 水墨 / 白描 / 矿物颜料视觉；色板取自传统矿物颜料（石青 #2E5C8A、石绿 #4A7C59、朱砂 #C3272B、赭石 #8C5A3C、藤黄 #D9A521、蛤白 #F4F1E8、墨 #2B2B2B）。数据呈竖排简册式分栏，进度以墨迹渐染表现，批注用朱砂小字。生僻字（𪁺𪁸、䍺、猼訑等）显示拼音注音，不留豆腐块。字体仅用系统衬线栈（思源宋体系），未部署任何商业字库 Web Font。

- **新手指引**：首次进入（无著录记录）自动播放六步引导，依次掠过舆地 / 技能 / 征伐 / 行装 / 行动 / 统计，讲解核心循环；完成后写入本地标记不再打扰，可在「设置」页「指引 → 新手指引」随时重看。
- **离线归来**：离山满 2 分钟后结算，弹出「离线归来」汇总（时长、效率、所得经验 / 著录 / 圃艺 / 物品）；短时离线仅以浮条提示，不打断。
- **常驻指引条**：舆地页顶部按当前进度给出下一步建议；其余页签顶栏同样常驻一条「下一步建议」（初学者的起点、可御使而未御使的异兽、刚解锁的山系、临阶突破的著录，或挂机编排提示），不靠弹窗也能持续引导；条末「前往 ›」可一键跳到相关页签；条末「✕」可关闭，设置中可重开。
- **移动端山系折叠**：窄屏（≤720px）舆地页默认收起尚未解锁的山系章节（保留「🔒 未解锁山系 N 章」开关，点按展开/收起），避免超长列表把地图与节点详情挤出首屏；PC 端山系列表始终全量常驻。
- **竖向侧边导航**：功能区块从顶部横栏改为左侧竖向侧边栏（PC 端常驻随页面滚动），主视图获得完整宽度展示当前行动与地图；窄屏（≤760px）侧边栏收为常驻图标栏（约 54px，只显示功能图标、不遮内容），点图标直接切页，点栏顶「≡」展开为带宽文字的菜单（228px，点遮罩 / Esc / 选功能后自动收起），布局与当代手游一致。「≡」落在书脊格里（与「山海经」同一行、高 54×书脊高），墨色只铺到书脊下沿便转纸色——若铺满整条吸顶区，左上角会出现一块比书脊高一截的纯墨空白，看着像缺了一块；栏底以一道细线隔出「设置」入口——它与其他功能一样是**一页**（不弹窗），外观 / 偏好 / 指引 / 存档 / 快捷键分栏排布，改任何一项就地重绘，顶栏因此彻底让出图标位；展开的宽菜单整体退到吸顶区下沿并铺纸色（渐变只服务于折叠态的对齐，展开态若沿用会把菜单头部误涂成书脊墨色），选中项为朱红淡底 + 左侧朱线，与桌面侧边栏同一套语言；书脊、仪表带、指引条整体让出左侧 54px，切换页签时侧栏零位移、指引条文本最多两行（不再把内容挤下去）。
- **自定义昵称**：「设置」页「偏好 → 游戏昵称」可随时设置或修改（最多 12 字，自动去首尾空白），保存后显示在顶栏标题后，随存档持久化；留空则恢复隐藏。
- **目标可见性**：讨伐页在「✔ 推荐 / 可讨 / ⚠ 危险」的胜算评估之外，额外标出当前节点已解锁、讨伐等级达标、非 BOSS 中经验效率最高的一只（朱色「宜讨」，与「✔ 推荐」兼具时合并为一枚，不并排），278 只异兽不再「不知道打哪只」；图鉴卡直接显示距下一阶的著录进度（如 7/10），满阶明示「得御」，收集线的前路看得见。
- **廛市清整**：行装页按稀有度阈值（凡品 → 瑰宝）实时预览可售原材料与总价，modal 二次确认后一键售出——食物 / 药品 / 装备 / 嘉种 / 嘉谷（烹饪与糈用基底）一概不碰，解决「挂机攒了一行囊材料却不知道能卖钱」的经济断档。
- **征伐页分层渲染**：竞技场（血条 / 回合 / DPS）与 278 只异兽的目标列表分开渲染——开战与结算只替换竞技场，并就地补上刚打完那张卡的著录数与「经验 ×0.88」递减标签，整份列表不再重建；目标卡另做布局绘制隔离（`contain` + `content-visibility`），滚动时只处理视口内的卡片。挂机连战不再整页淡入闪烁、不再把滚动位置弹回顶部。
- **连杀知止**：连续讨伐同一只异兽，经验每次 -3%、最低 60%（卡面页脚实时显示「经验 ×0.88」并附悬浮说明）——治「挂机无脑刷一只低级怪」的惰性，又不碰材料线与著录度；换一只异兽即刻恢复全额，战败中断链条，BOSS 不递减。
- **方国求购**：墟市新增动态求购订单板——常驻 3 单，只求购已解锁山川出产的原材料（标注「䧿山来求」等方国名），溢价 1.3~1.8 倍于基准价，整批 30 分钟轮换（也可「另访方国」主动换批，共享冷却）。行囊备齐即可交割得贝币与商旅经验，已交割的单划掉留存至整批轮换；可交割的单会进「推荐买卖」。给贝币一个「卖材料」之外的第二出口，采集从此有明确目标。
- **小单块 · 渐进披露**：各页条目默认只保留「图标 + 名称 + 关键数值 + 主操作」的小单块（网格密度上调，一屏展示更多条目）；山海原文、注解、神话、技能描述、材料来源、异兽形态与掉落等明细信息默认收起——PC 端鼠标悬停即出详情气泡，移动端点按则从底部滑出详情抽屉（bottom sheet，当代手游标准详情模式），点空白处或 ✕ 关闭。

- **顶部状态条**：原悬浮于视口底部的动作条上移并入顶部吸顶区，与精简后的顶栏（总等级 / 已录 / 贝币 + 最右一枚增益图标）、指引条一体吸顶；**只显示当前行动、行动进度与「停止」**——气血在征伐页的战斗面板里已有，此处不再重复；主视图不再被底栏挤占。「停止」在确有可停的行动时出现——采集 / 制作等行动如此，往讨亦然：战斗中点它即结束当前这场且不再自动接战，状态栏随即回到「空闲」。**战斗不跨会话保留**：关掉页面再进，上次的往讨会中止并提示「可前往征伐页重新开战」，不会停在「往讨：X」却不动（战斗由运行时变量驱动，恢复战斗态必然卡死）。
- **闲置兜底**：放置游戏不留「死档」——无行动、无战斗、巡历未跑且持续 8 秒后，自动接上默认行动：优先执行巡历页设过的兜底动作，否则在当前节点上樵采 / 采玉 / 渔 / 采药（取等级达标的第一个）。状态栏会标注「（兜底）」并在首次启动时说明一次；手动停止后再次闲置仍会自动接上，「设置」页「偏好 → 闲置兜底」可随时关闭。
- **成就庆典**：长线成就（里程碑）达成时除浮条提示外，附粒子庆祝动效。
- **御使引导**：异兽首次著录至「通形」（可御使）时，弹窗引导前往「御使」入槽；「御使」页签常驻角标显示可入槽未御使的异兽数量，避免错过。
- **推荐前往**：「舆地」未涉足的已解锁山川以「荐」标出，可御使异兽所在之山以「御」标出（红框高亮），目标一目了然。
- **连战胜场**：讨伐连胜累计，达 3 连及之后每 5 连以轻量粒子与浮条庆祝；战败清零。
- **五行相克助手**：征伐页实时显示「敌我属性」生克关系——克制 ➤ / 被克 ↩ / 相生 ↻（伤害 ×1.15）/ 相持 ↔ 一目了然；被克或相持时给出**宜用属性**（克敌方的属性，如敌木宜用金）与「⚡切X属」一键切换（祝术五行即时生效并刷新提示）；战斗中双方血条、血量数字与 DPS 预估逐帧实时刷新。
- **新山系解锁**：舆地 / 履险升级使新山系可达时，以浮条提示「🔓 新山系解锁：X」，不会漏掉可探索区域。

- **移动端手势**：在内容区左右滑动即可切换页签（环绕），小屏下加大按钮与页签点按区域，便于触屏操作。

- **售价走势曲线**：「墟市」头部用微型折线图记录「售价加成」随商旅等级、营造、御使、征兆的成长轨迹，卖出力一目了然。

- **技能→产出地跳转**：「技能」页每个采集技能卡附「📍 前往产出地」按钮，一键跳到该技能对应资源所在的山系与节点；技能与产地不再割裂。
- **图鉴分类完成度**：「图鉴」页顶部按当前分类显示「本类 X/Y」完成进度，并以玉色进度条直观呈现，切换异兽/山川/百物/祠典时各自统计；右侧仍保留全局「总录」进度。
- **方块语言（全站十三页统一）**：技能 / 制作 / 征伐 / 行装 / 图鉴 / 祠礼 / 墟市 / 舆地 / 御使 / 征兆 / 营造 / 墟市出售 / 田地都用同一套正比例小方块——一格一味，图标为主、名字在下、关键数值做角标，靠图形扫读而非逐字；手机三列、桌面最多十列。点按即执行该页的主操作，明细一律收进浮层：
  - 技能：右上等级、底部经验条；点开看描述、产出地、材料来源与持有缺口。
  - 制作：点按做一件（做完即停），右上「连」做到底；锁定只让图标去色，点按提示缺哪几样、差多少。单件武器 / 装备不必再被迫连做，离线结算同样遵守件数上限。
  - 征伐：点按即开战；左上五行、右上「宜讨」、左下「宜金」（一键切克制属性）、右下「×0.88」连杀递减，威胁大小由边框色表达，气血 / 攻防 / 经验 / 掉落 / 所在山在浮层。278 只异兽一屏扫过二十余只。
  - 行装 / 图鉴：行囊带稀有度左缘色、数量与价值压角；图鉴未见者仍是虚线框。
  - 祠礼：方块上是「首字朱印」（北次一·瘗礼 → 瘗），二十二套礼制一眼可分；点按即祭，缺祭品会说清缺哪样、差多少。
  - 墟市：点按买一份，右上「×10」买十份；价格在名字下方，份量与说明在浮层。
  - 舆地：山系与诸山皆方块，所在山描边、推荐动作带色，山志原文 / 注解 / 神话 / 产出 / 异兽收入全在浮层，动作按钮常驻。
  - 御使：可御使异兽平铺，点按即御使；在槽者描青只读，增益幅度与著录次数在浮层。
  - 征兆：印记字按吉（青）/ 凶（朱）/ 中（金）着色，生效中整卡描金并在角标显示剩余时长；效果与原文在浮层。
  - 营造：建筑首字印记 + 营造等级，点按即营造；已成描青带 ✓，材料与效用在浮层。
  - 墟市出售：点按售 1，右上「全」一键售清；售价用金色数字，单价与持有量在浮层。
  - 田地：空田虚线框点按开「择种」浮层（未持有 / 未达级的置灰并说明原因），植入后为实线方卡——作物图标 + 名称 + 贴底细进度条 + 剩余时间，即将成熟描金，成熟自动收获。
- **材料来源跳转**：「技能」页制作类技能卡列出「材料来源：📍 山A · 📍 山B…（等 N 处）」，去重汇总该技能所有配方材料所在的山系，每处可一键跳转；并附「材料：玉膏 0/1✗ · 丹木 3/2✓」逐材料「已持有/缺口」状态（缺口标红），一眼看清离造出还差什么。「图鉴」详情中异兽/百物条目也附「📍 前往讨伐/产出节点」按钮，看完即能去采集或讨伐。
- **叙录（关于本作）**：侧栏末页是一卷「卷首」，取刘向校书「条其篇目、撮其指意」的旧例。六栏：**缘起**（世界观：禹刊木记山、伯益次为《五藏山经》）、**此身**（玩家身为著录者，简帙既盈此卷遂成）、**体例**（舆地→采集→著录→制作→御使→祠祀的循环，附八条细目）、**卷帙**（山系 / 山川 / 异兽 / 六凶 / 图鉴 / 技艺 / 征兆 / 祠礼 / 观象 / 营造的**实时**计数）、**稽考**（底本、自研声明与免责）、**成书**（版本 / 代号 / 更新 / 形态 / 存档 / 在册时长）。桌面收在 760px 居中的书页宽度，手机上为通栏。

- **节点著录进度**：「舆地」选中某山时，详情面板顶部显示「已著录 X/Y 种」（该山可著录的物产+异兽中已录数），录毕提示「此山录毕 ✦」；节点列表项右侧也带「录 X/Y」小标，不点开即可扫出哪座山还有遗漏。节点详情的异兽区逐只标注「✓录N / 未录」，一眼看清这座山哪些兽还差著录。
- **征兆总效应弹窗**：顶栏「⚡ 征兆数」可点击，弹窗汇总所有生效征兆的**总效应**（如「采集效率 -20% · 离线收益 -25%」）与逐条方向/剩余时长/范围，挂机或舆地时也能随时读懂当前吉凶影响（祠祀页同样列出）。
- **战斗预估耗时**：交战中显示「预计击杀 ≈ Xs · 你 DPS≈N · 敌 DPS≈M」，并据双方输出与气血提示「⚠ 可能撑不住」，开打前即知胜负走向（已含五行克制加成）；该倒计时随怪物血量**实时刷新**，越打越接近归零。
- **状态变化即刻上屏（实时性）**：田地成熟自动收获后卡片**即时翻面**为空田、进度条与剩余时间每秒跟进（即将成熟描金）；征兆到期 / 新触发时祠祀页的 active 态、总效应与禛解行就地补绘；书脊增益浮层展开时倒计时同步递减；巡历队列任务达成后「当前」标记与完成轮数即时更新；廛市售价走势按 60 秒间隔采样，挂机也有轨迹。以上都不需要切页刷新。
- **键盘可达**：所有方卡带 `role=button`，Tab 聚焦后回车 / 空格即等于点按；`1-9/0` 直切侧栏十档，`S` 存档、`Q` 停止、`Esc` 逐层关闭（浮层 → 弹窗 → 抽屉）。
