## v1.31.21 · 2026-10-26

**修：蛊雕「好几座山都有」**
- 现象：战斗页里同一只兽出现在多个山系分组下，看起来像它遍布全书。
- 根因不在数据。`taofaListHtml` 与 `loadBeastGroup` 都把「宜讨」无条件插到每组队首：
  ```js
  const ordered = pick ? [pick, ...g.list.filter(x=>x!==pick)] : g.list;
  ```
  pick 不属于该组时也被插进去，于是展开二十四个山系就看见二十多张同一只兽（产地还写着同一座山）。
  哪只兽是宜讨，哪只就「遍地」——蛊雕只是被撞见的那一只。
- 修法：抽 `orderForGroup(list, pick)`，`list.indexOf(pick) < 0` 时原样返回；
  两处渲染（首屏 / 展开）走同一函数。数据侧确认蛊雕只有一处产地：鹿吴之山。
- 「可猎」组与南次三经组本就有三只同山（犀/兕/象），属**按用途另列**，标题补「另见南次三经」，
  免得玩家以为两座山各有一只。
- 测试第 115 节：函数原文抽进沙箱实测（外来宜讨不插入、本组宜讨置顶不重复）+ 蛊雕唯一产地。

**观象扩点：7 → 11 处，并接上离线效率**
- 24h 基线之后，「观象 +1h」已不是刚需；只加分母没人去。于是给它第二个用处：
  **观满 6 处 +2% / 9 处 +3% / 11 处 +5% 离线效率**（阶梯，取最大的 n ≤ 已完成数），
  效率上限同步从 0.85 抬到 0.90——否则满级玩家贴着上限，这 5% 又成空气。
- 新点全按原文方位补，且避开已有谒见点（同山两个一次性按钮会互相顶掉）：
  - 西山 · **崇吾四望**（西望帝之搏兽之丘，北望冢遂，南望䍃之泽，东望𧕯渊——四向俱全仅此山）
  - 西山 · **不周河源**（东望泑泽，河水所潜也，其原浑浑泡泡）
  - 北山 · **盐贩之泽**（景山：南望盐贩之泽，北望少泽）
  - 中山 · **河林**（敖岸之山：北望河林，其状如蒨如举）
- 五章皆有可观：南山 3、西山 2、北山 1、东山 4、中山 1（+ 观瑞 2）。
- 统计页新增「观象加成 N/11 处 · 离线效率 +X%」并预告下一档还差几处。

## v1.31.17 · 2026-10-26

**卷二 · 难度带（二周目）**
- 先说为什么**不能**按「再来 81 级」排：玩家战力上限就在九九满装——轮回印只加修为与采获，
  遗物只加防御气血，没有任何一条线让伤害继续涨。按 162 级排，怪对满装玩家就是无解。
  所以卷二是一条**固定高度**的带：`TUNING.CYCLE.BASE = 82`，原 Lv1–9 → 82、Lv10–18 → 83 … Lv73–81 → 90。
- 形态是「同山同兽的更强一遍」：名号加「卷二·」，三维与经验**先除回标准曲线、再乘回标准曲线**，
