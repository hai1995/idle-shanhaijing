# 版本记录

> 只记「为什么改」，不记「改了哪一行」。更细的取舍过程在仓库根 `README.md` 与各次提交信息里。
> v1.15 之前的版本号未逐条归档，按主题合并记在文末。

## v1.31.2 「五臧 · 问神」 · 2026-10-25

- **再谒不再当免费经验机**：问神上线后 `doAudience` 可无限重复，经验却一直按首谒那档给。实测离线一小时：首谒 +7,496 / 再谒 +60,480 / 再观 +4,500 —— 不产任何物件的动作比同长度观象高十三倍。改为首谒 336、再谒 40（与观象同例），改后三个数落在 7,496 / 7,200 / 4,500。
- 删掉一处每次调用都记的日志（离线一小时 180 条）。

## v1.31.1 · 2026-10-25

- **问神不在自动途径弹窗**：队列与离线结算都会反复调 `doAudience`（离线一小时 180 次），每次都弹会盖出一屏关不完的弹窗。改为只有「玩家自己点的那一趟」才弹（`opts.oracle`），提示日志 60 秒最多一条。
- 异迹索引里，录满的谒见点写「已录 · 可问缺录」；弹窗底部加「去图鉴看未录」。

## v1.31.0 「五臧 · 问神」 · 2026-10-25

- **问神**：二十处谒见点录满之后再谒，山神报出本系尚未著录的物产 / 异兽 / 神祇（按门槛升序，点一行即定位那座山）。纯信息、不产物件，故无冷却。按钮文案随之从「谒见」改为「问神」。

## v1.30.0 「五臧 · 同好」 · 2026-10-25

- **同好一栏**：「叙录」页写 QQ 群号（`GAME_META.group`），可一键复制；剪贴板不可用时弹可手选文本。
- **战绩**：「录一卷」把修为 / 技艺 / 著录 / 六凶 / 最高强化 / 单轮最快凑成一段纯文本，便于群里对进度。这几个字段即将来排行榜要收的字段。
- 修：统计页「凶神」的**就地刷新**仍写着 `/7`（静态渲染改好了，patch 又改回去）；成就进度数与进度条同步纳入刷新。

## v1.26.0 「五臧 · 齐礼」 · 2026-10-25

- **十四条祠礼在解锁时根本做不出来**：通用祭具（瑜/酒/珪/吉玉/雄鸡/白鸡）等级一刀切在 66，最狠一套差 39 级。祭具改按「首次用到它的那套礼」定级（28–41），礼器配方贴到「山系门槛 +3」。
- 根因是**审计在空转**：检查读的是 `RITES[].cost`，而祭品在 `Recipes(type:'rite')` 里——遍历空数组，一直报零问题。补「确实查过 28 套」自检。
- 营造页同套排序与缺料提示；审计补营造材料可达性。

## v1.22.0 「五臧 · 轮回」 · 2026-10-25

- 存档 `SAVE_VERSION 3 → 4`。
