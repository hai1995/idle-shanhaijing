# 路线与待办

> 这份文件的作用是「下次接手时不用重新想一遍」。分四块：想做的、已知空白、待验的账、已否决的（附理由，避免重复讨论）。

## 一、想做的

### 1. 排行榜（网游化的第一步）

数值已经齐了，缺的是「怎么收、怎么比」：

| 维度 | 数据来源 | 现状 |
|---|---|---|
| 修为 | `Game.stats.totalXp` | 只增不减、终身累计 ✅ |
| 轮回次数 | `Game.rebirth.count` | ✅ |
| 单轮最快 | `rebirth.history[].sec` | ✅（最多 10 条） |
| 三签完成数 | `stats.bounties` | ✅ |
| 最高强化 | `Game.enhance` 最大值 | ✅（`bestEnhance()`） |
| 著录条数 | `recordedCount()` | ✅ |

要做的事：一个提交入口（把 `shareText()` 的字段发到一个收集端）+ 一张榜。**不做在浏览器里直连第三方**，需要一个极简后端（`server/` 下已有零依赖存档服务的骨架可复用）。

### 2. 转生的配套内容

转生循环已经能跑通（每转 +30% / 起手 +8 级 / 提速 24%→78%），但**轮回之后世界没有变化**：还是那 447 山、那些配方。可做的事：

- 轮回专属条目（每转解锁一件「前世遗物」，可选加成一两项）
- 二周目难度带（同山不同怪，等级从 82 起排；`TUNING.MAX_LEVEL` 语义已是「本卷上限」，留了口子）

### 3. 中期的空窗

30–50 级这一段，能做的事多但都不「新」：采集、制作、祠礼、讨伐。可选的方向：中期专属的一次性地点（像观象那样有明确回报），或让「方国求购订单」承担这段的经济目标。

## 三、待验的账（按已用方法继续量）

已用「同一口径、逐项实测」的方法抓到过：怪与玩家成长曲线错位、食物从不被吃、祠礼 14 套做不出来、六凶分母错、再谒经验 13 倍溢出。还没量的：

1. ~~**离线各路径的产出对比**~~（已测）：樵采 375,756 / 谒见 7,200 / 观象 4,500（每小时，40 级）。制作类在 v1.31.4 一并查了：一小时 3600 件绳（每件 2 秒），有灶窟 4000；材料照扣。查出三条「离线与线上不同口径」并已修（产地只认主产地、不认越级、制作耗时写死）。
2. ~~**三签的赏钱上限**~~（已测，v1.31.5）：满级单签 141–536 贝，占同等级一小时采集收益（约 50 万）的 0.03%。结论：三签是「顺手彩头 + 完成度」，不是经济来源；可循环的赏钱不能提，要加激励宁可加在首签/连胜上。见 `docs/BALANCE.md` 三。
3. ~~**祠礼的收益/成本比**~~（已测，v1.31.5）：26 套小礼成本中位 130 贝，最慢 82 秒回本，增益/成本比中位 1:314；只有羭山百牲斋（31,400 贝、56 分钟回本）配得上「大祭」。结论：祠礼是低成本 1 小时 buff，不做经济杠杆。测算已搬进游戏（祠礼浮层显示「祭品折价 / 本域时采 / 此礼多得 / 回本」）。见 `docs/BALANCE.md` 一。
4. ~~**装备强化的期望消耗**~~（已测，v1.31.5）：+30 中位 225 次、4,746 炭、117 万贝，折约 6 小时挂机。附带结论：火候机制是必需的——去掉火候后同样模拟 300 次全部发散。见 `docs/BALANCE.md` 二。
5. ~~**中期（40–60 级）的单杀时长**~~（已测，v1.31.7）：按等级分段看 TTK 分布——中位 10.2 / 15.3 / 16.5 / 17.1 秒，p90 14.8 / 21.6 / 22.6 / 23.8 秒，无一只越 32 秒，存活/击杀比 2.1–4.6 倍。**整条线是平的**。复跑：`node scripts/measure-ttk.js --detail`。见 `docs/BALANCE.md` 五。
6. ~~**修为与轮回印的长期曲线**~~（已测，v1.31.7）：单位时间修为 ∝ 乘区²（第 7 转是首轮的 10 倍）；第 6→7 转因起手等级封顶出现 6% 凹陷（非 bug，见 `docs/BALANCE.md` 六）。复跑：`node scripts/measure-rebirth.js`。

## 四、已否决 / 需谨慎

| 想法 | 为什么不 |
|---|---|
| 拆掉 81 级上限 | 447 山的等级都排在这一段里，往上没有内容可接；数字涨而山不动，反而抹掉「练满」这个终局目标。无上限交给修为。 |
| 重复谒见给物件 | 会变成第二个祠礼，且 20 处 × 无冷却＝稳定的材料产出，直接冲击经济。改为给信息（问神）。 |

| 统计/成就的判据各写一份 | 「南山舆图」数全部到访节点、「六凶 x/7」都是这么错的。同一件事只留一处定义。 |
| 账号系统 | 暂不做（项目主明确），云端存档以自托管参考实现代替。 |
| 给祠礼加「香火钱」（贝币门槛） | 账已经算清：小礼增益/成本比 1:314，回本最慢 82 秒。再加一道贝币门槛，只是把「点一下」变成「点一下并扣钱」，不产生任何新的决策；而且续祭是自动的，扣钱会把离线挂机变成「悄悄烧钱」。贝币出口该另找（见「市廛只有 12 个 SKU」）。 |
