## 一句话

夜间模式补齐了现场那条（此前整页转暗、只有它还是白纸）；征伐成为第六种行动画面。

## 一、现场不跟着变暗

用户截图：整页暖炭底，仪表带下面那条仍是白纸。三处写死：

| 位置 | 写死 | 改法 |
|---|---|---|
| `.sc-wrap` | `#F5F2E8 → #EAE5D6` | `--paper-3 → --paper` |
| `.sc-sky` | `rgba(255,255,255,.55)` | `--sc-sky`，夜间压到 `.045` |
| `SCENE_INK` | 五系深墨 | 加 `SCENE_INK_NIGHT`，同色相提亮到 4.5:1+ |

还有一个坑：现场颜色是**渲染时写进内联样式**的，不是 CSS 变量，
所以 `applyTheme` 里必须重画一次——否则切到夜间后留着一身日间深墨，整条看不见。

## 二、六种行动各有其物

| 行动 | 物 | 动 | 驱动 |
|---|---|---|---|
| 采集 | 锄 + 土堆 | 举—落，土粒迸开 | JS 每帧 |
| 制作 | 锤 + 砧 | 同一套举落，柄短一截 | JS 每帧 |
| 莳植 | 灌木 | 风里轻摆 | CSS |
| 观象 | 星 + 月 | 闪 | CSS |
| 谒见 | 三级台阶 | 静 | — |
| 征伐 | 剑 + 兽 | 缩半步、前冲 9px、命中迸火星 | JS 每帧 |

### 征伐此前为什么没有画面

`sceneState` 对战斗直接 `return null`，理由写的是「征伐页自有战斗画面」。
但那是**页面**上的血条与战报；玩家挂机时停在别的页签，就什么也看不见。

### 两条约束

**① 节拍取「几秒一击」**，不是「几秒一采」。动画周期必须等于产出周期，
否则「一击一伤」的因果错位。时间源换成 `Game.combat.timer / playerAttackInterval()`。

**② 工具只换尺寸，不换时间轴。** 节奏属于「人」，造型属于工具：
`SCENE_KIT` 只给柄向量与刃宽，`SCENE_SWING` 两种工具共用。
