# 系统手册

每节格式：**做什么 / 入口 / 关键常量 / 口径与边界**。数值以 `TUNING` 与代码为准，这里只记「决定手感的那几个」。

---

## 1. 技艺与等级

- 26 门技艺对应 26 个山系；`levelOf(id)` 为当前等级，上限 `TUNING.MAX_LEVEL = 81`（九九）。
- 升级需求：`round(A·L^2.15 + C·R^L)`，`A=20, C=10, R=1.048`（累积表 `_xpCum`）。
- 阶位：每 9 级一阶，`TIER_NAMES = 一九…九九`。
- **81 是「本卷」上限，不是全局硬顶**：全书 447 山的等级都排在这一段里，再往上没有内容可接。无上限的成长维度交给「修为」（`stats.totalXp`，终身累计）。

## 2. 采集

- 入口 `startActivity('gather', itemId)` → `doGather`。必须站在产地（`it.node` 或 `it.nodes[]` 之一），积石之山 `allYield` 例外。
- **越级采集**：技能差 8 级以内仍可动手，效率 `max(0.35, 1 - gap×0.08)`。
- 间隔：`gatherInterval(skill)` 基础 3.4–4.5 秒，按技艺等级与工具（斧/镐/网）递减，下限 1.05 秒，再除以 `gatherSpeedMult()`。
- **采获 vs 采集速度**：`yield` 通道走「一次得双份」概率（`GATHER_DOUBLE = 0.25`），`gather` 通道缩短间隔。文案上「采获 +30%」实际是产量 +15%（`riteRealYield` 折算），界面对此有统一说法。
- 地气：流沙（无橐驼则 ×1.25 间隔）、百仞（×1.18 间隔 / 采获 +10%）、旱河（渔获随季节 ±30%）。

## 3. 制作

- 入口 `startActivity('craft', 'type::out', {times})`。`times` 省略表示**连作到材料用尽**，界面给「连」按钮。
- 离线按次数结算（`activitySeconds` 给单次耗时，`doRecipeAction` 每次产 `qty` 件）。
- 材料不足时不给「原料不足」四个字了事：浮层里逐项列出缺什么、缺几件、去哪儿找（`itemSources`）。

## 4. 战斗

- 入口 `startCombat(id, {times})`，弹出「战斗」面板；次数默认 ∞。战法（姿态）四选一：无 / 疾攻 / 沉稳 / 破军，各改伤害·防御·攻势·减伤。
- 伤害：`playerDamageRange()` → 兵器 + 技能，叠五行（克 ×1.35 / 被克 ×0.75 / 同属 ×1.00 / 相生 ×1.15）、词条、绝技、势。
- 敌方属性：血 `L^1.26`、攻 `L^1.02`、经验 `L^1.36`；人形凶兽血 ×1.15、攻 ×1.3。BOSS 走手填数值（血 1800–3800，按目标单杀时长反推）。
- **进食收口在 `combatTick` 末尾**：伤害可能来自普攻、特殊技、蛇毒三条路，各自 `return` 会漏。`autoEat` 只在气血 ≤ `Prefs.autoEat` 时吃一份。
- **连败三阵收兵**：同一目标连败 3 次停止自动复讨（`stats.deathStreak`），并在弹窗提示「已连败 N 阵」。
- **阴阳嬗变**（九婴/帝江）改的是战斗上下文 `c.el`，绝不写 `Monsters[id].el`（曾污染静态表）。
- 开战前的账：`combatEstimateInner` 给「承伤约 N 倍气血 / 需备 M 份吃食」，折算用**有效回血** `min(食物回血, 气血×(1-阈值))`。

## 5. 祠礼

- 28 套礼，行祭给**该山系**限时采获加成（`RITES[].yieldBonus`，1–2 小时）。
- **加成不是直接乘件数**：它加的是「得两份 / 三份」的几率，真实产量 ≈ `riteRealYield(b) = (b×0.5 + b×0.12) / 1.25`，+30% 的礼约合 +15%。线上、离线、面板文案三处都必须走这个函数（v1.31.5 修掉了离线直接乘 1.30）。
- **祭品在 `Recipes(type:'rite').cost` 里**，不在 `RITES`。`riteState(id)` 给「材料够几套 / 等级够不够」。
- 续祭：`riteAuto[id] = true` 到期前 60 秒自动重备；材料不够转 `riteStall`（待料），`tickAutoRites` 每秒检查。
- 离线：`settleRitesOffline` 按离线时长补算已开续祭的礼。
- **这一礼值不值**：`riteWorth(id)` 把祭品折成贝币、按该域最高价物产估一小时产出，给出「多得多少 / 多久回本」。面板浮层与 `docs/BALANCE.md` 的表都读它——别再手写一处「约合 +15%」的估算。实测：小礼成本中位 130 贝、最慢 82 秒回本；羭山百牲斋 31,400 贝、56 分钟。

## 6. 观象 / 谒见 / 问神 / 灌木

- **观象** 9 处（南山 5 + 东山 4）：首次 +1 小时离线上限（`offlineCapHours`），重复给 25 观象经验。
- **谒见** 20 处：首次录神祇（`records[deityId]`）、触发对应征兆、给「初谒之赐」；**再谒**改问「此系还缺什么」（`regionMissing` → `UI.showOracle`），只给信息不给物件，故无冷却。
  - 首谒经验 `200 + 门槛×4`，再谒 `40`（与观象同例）。
  - 自动途径（队列 / 离线）**不弹窗**，`doAudience(nodeId, {oracle})` 显式开关；提示日志 60 秒最多一条。
- **灌木** 3 处（峚山丹木 5 岁 / 咸山器酸 3 岁 / 发鸠山精卫 200 阶）：每阶耗一份材料，给圃艺与著录经验，完成给物。

## 7. 御使

- 槽位 = `beastSlots()`（随御使技艺，九槽）。只有著录到「通形」（tier ≥ 3）的异兽可上阵。
- 增益按著录阶缩放：`scale = 0.6 + 0.1×tier`。
- **选优**：`deployScore(id)` 把各增益折成百分比当量（防御 1 点 ≈ 0.75% 生存），成对御使（蛮蛮）占两槽、分数折半；`autoDeployBest()` 整体重排。
- 御使的 `hp/def` 类增益进 `playerMaxHp` / `totalDefence`，不是空转字段。

## 8. 三签

- 常挂 3 条短目标，做完一条即补一条，赏贝币。
- **记的是相对增量**：`base` 是抽签那一刻的计数，只认之后的变化（老纪录不会一次性点亮）。
- 各签次数与赏钱**分开定**：采集一秒一下、祠礼要备祭品，共用系数会让采集签刷爆经济。满级最贵一签 ≈ 536 贝。
- 换签免费但进度清零；抽签排除项要单独传（`bountyPull([oldId])`），否则会抽回原签。

## 9. 轮回（转生）

- 凭据：任一技艺至 81。第 N 转起手 `min(56, N×8)` 级；每转 **+30% 修为、+10% 采获**。
- **只重置技艺等级与经验**：著录、图鉴、成就、装备、贝币、地图、营造、御使、修为、轮回印全保留；舆地与履险也不重置。
- 每轮成绩入册（`rebirth.history`，最多 10 条：用时 / 本轮总等级 / 最高技艺）。
- 提速实测：24% → 41% → 53% → 63% → 71% → 78%（逐转）。若把 `XP` 调回 0.08，转生只省 8%，等于安慰奖——测试里钉了「第一转重回九九 ≤ 首轮的 82%」。

## 10. 离线

- 效率：`0.55 + 0.05×观象数`，封顶 0.85；上限 `12h` + 观象/建筑/成就加成。
- 两条入口：`settleAway(seconds)`（页面活着时的时间）、`settleOnBoot()`（关页重开，读 `…_time`）。
- **往讨估算**：`场次 = 秒数 ÷ (击杀时长×1.25 + 2)`；撑不住的部分靠背包吃食补，补不上就打到断粮为止，并在总结里写「每场需 N 份，只够支撑 M 场」。
- 离线也认：BOSS 专属材料、贝币、神兵（按场次折算一次判定）。
- 结算后刷新落盘时间戳，同一段不会算两遍。
- **离线与线上必须同口径**（三条曾不一致，v1.31.4 修）：
  - 采集的产地判定按 `it.nodes[]`，不能只认主产地 `it.node`（309 件物产是多产地）；
  - 越级 8 级内可硬采、效率打折，离线同样允许（原先直接不给）；
  - 制作每件耗时取 `currentActionInterval()`，这样灶窟（×0.9）与毕方「讹火」（−20%）在离线下也生效（原先写死 2.0 秒）。

## 11. 强化与装备

- **五档**：凡 / 良 / 精 / 珍 / 神，`mult = 0.86 / 1.00 / 1.16 / 1.30 / 1.55`，强化上限 `12 / 18 / 22 / 26 / 30`。基准曲线 `GEAR_BASE`，测试按容差带校验。
- 强化概率：`ENHANCE_RATE[30]`，100% → 2.6%；火候每格 +0.08（封顶 +12%），淬火炉再 +6%，总封顶 95%。
- **十级以上失败归零**（`ENHANCE_SAFE = 10` 以下只损材料）；十级以上一败俱伤是「神秘感 + 风险」的来源。
- 火候：失败累积、成功不清空（早期「成功退一半」导致系统死局）。
- 神兵：7 件，BOSS 6% 掉，带 `DIVINE_EFFECTS`（破甲/饮血/疾风/裂甲）。
- 词条：`AFFIX_POOL` 按槽位取，重铸换盐（`affixSalt`）重新掷。

## 12. 市场 / 订单 / 圃艺

- 市廛：12 个 SKU，多为祭具与种子（含 74/78 级后期货）。回收价 `SHOP_BUYBACK = 0.7`——**低于 1 是为了堵住「低买高卖」套利**（满配火种曾净赚 15 贝/轮）。
- 方国求购：`TUNING.ORDERS` 每 30 分钟 3 单，溢价 1.3–1.8 倍，交单给经验。生成在 `interact.js:refreshOrders`。
- 圃艺：6 块田，播种 → 成熟自动收，偶尔回赠种子；速度受 `farmSpeedMult()`（御使/建筑）影响。

## 13. 图鉴与收集

- 1122 条，五阶揭示（`reveals[]` 与 `MASTERY.THRESHOLDS [1,10,25,50,100]` 对应）。
- 「仅未录」筛选 + 名/注音检索；详情里可「前往产出/讨伐节点」。
- 收集成就按分类完成度发贝币，入口挂在图鉴页顶部（不另开一页）。
